# College Media

College Media is a frontend social-media-style web application built using **React** and **Tailwind CSS**.
The project focuses on creating a clean feed experience where users can create posts and view updates.

---

## 🚀 Features

- Modern post input box (similar to LinkedIn)
- Feed section displaying user posts
- Action buttons for:
  - Photo upload
  - Video upload
  - Event creation
  - Article writing
- Clean and responsive UI
- Reusable React components

---

## 🧩 Components Added

### 🔹 InputBox Component
- Allows users to start a post
- Includes action buttons with icons:
  - Photo
  - Video
  - Event
  - Write Article
- Built using **React Icons** and **Tailwind CSS**

### 🔹 Feed Component
- Displays a list of posts
- Uses dummy post data for UI demonstration
- Renders individual posts using a reusable `Post` component
